# Flows

## (no git branch) sensor capability prototype
Trigger: user taps Start in `MainActivity`. It requests POST_NOTIFICATIONS on API 33+ and calls `startForegroundService(SensorService)`. The service posts an ongoing notification with a Stop action. It registers listeners through public APIs for the wake-up variants of tilt detector, significant motion and device orientation, and for screen on/off/user-present broadcasts. Each registration result and each event is appended to `filesDir/events.log` with interactive, charging, doze and battery state. The log is capped at 2 MB (cleared when exceeded). The UI shows the sensor list plus the log, and exports it as plain text through the share sheet. Stop, or the notification action, unregisters everything. Failure paths: a sensor missing from the public API is logged and skipped. If the OS kills the service, no restart is attempted (`START_NOT_STICKY`).
